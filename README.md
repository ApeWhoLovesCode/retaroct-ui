# retaroct

基于 `taro` 小程序封装的组件库。

#### 相关技术

`react` , `hooks` , `ts` , `taro`

[线上地址](http://retaroct-ui.codeape.site/)

## 使用组件库

```
npm i retaroct-ui
```

## Getting Started

```bash
# 推荐使用 node 16
nvm use 16
# 没有安装 taro 的可以安装一下
npm install -g @tarojs/cli@3.4.11
# 安装其他依赖
npm i
```

打包文档(Build documentation)

```bash
$ npm run docs:build
```

运行项目(Start the dev server)

```bash
$ npm run start
```

打包(Build) 发布 npm

```bash
$ npm run build
```
